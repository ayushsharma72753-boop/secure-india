# 🇮🇳 SECURE INDIA - Made for Safe Roads

> An initiative by a Visually Impaired (PWD) citizen to make Indian roads safe for everyone.

**Live Link:** https://secure-india.vercel.app/

### About The Project

SECURE INDIA is a citizen reporting platform where anyone can report civic problems like Potholes, Garbage, Electricity, and Water issues with live GPS location.

This project is made by me, a Person with Disability (Visually Impaired). When I go outside, I cannot see potholes clearly, especially at night. Many times I have almost fallen. This is dangerous not only for people like me but also for elderly, children and every citizen. So I built this to solve a real-life problem.

### Why This Project Is Special?

1. Made by PWD for Everyone
2. Smart Department Routing: Water -> Jal Vibhag, Electricity -> Vidyut Vibhag, Pothole/Garbage -> Nagar Nigam / PWD
3. 50 Meter Pothole Alert for accident prevention
4. Global Admin Lock for security
5. Live Stats Dashboard (Total Users, Total Reports, Fixed, Pending)

## Research Behind The Project

### Topic: Why Trees Uproot in Storms but Humans Don't?

During aandhi in Kanpur, trees uproot and fall on roads, which creates new potholes and breaks bijli wires. But humans don't fly. I researched why.

**Main Formula:**
Fd = 0.5 * p * v^2 * Cd * A
p = air density (1.2 kg/m3), v = wind speed, Cd = drag coeff, A = Area

**Comparison at 90 kmph storm (25 m/s):**
- Tree (10m): A=15 m2, Cd=1.2 => Force = 6750 N
- Human (1.7m): A=0.6 m2, Cd=0.8 => Force = 180 N
- Result: Tree faces 37x MORE force!

**Why Tree Fails:**
1. Sail Effect: Leaves act like 15 m2 parachute
2. Lever Effect: 6750N at 10m height = 33,750 Nm torque on roots
3. Muddy Soil: Rain reduces root grip by 70%

**Why Human Survives:**
1. Less Area: Only 0.6 m2
2. Can Crouch: Area becomes 0.2 m2
3. Can Adapt: Can hold pole, bend

### Experiment
**Materials:** Table fan, small potted plant, toy figure
**Process:** Kept both 1m away from fan, increased speed Level 1 to 3
**Observation:** Plant uprooted at Level 3, toy only slid
**Conclusion:** Proved Fd proportional to A. This helps Secure India predict storm damage zones.
